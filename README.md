# Personal Portfolio Website 🌐

Welcome to the repository for my personal portfolio website, hosted via **GitHub Pages**. This site showcases my professional background, education, technical certifications, and project achievements.

👉 **Live Demo:** [https://shad-ahamad.github.io](https://shad-ahamad.github.io)

---

## 📌 Features

- **Interactive Showcase:** Highlights professional experience in product management, supply chain operations, and engineering.
- **Education & Credentials:** Displays academic qualifications from **KUET** and **Rajuk Uttara Model College**.
- **Certifications:** Showcases industry certifications including **CCNA**, **Supply Chain Management (SCM)**, **Cybersecurity**, and **Cyber Hygiene**.
- **Responsive Layout:** Fully optimized web layout using `index.html` and custom image assets.
